## 一、12 条跨课通用原则 (`P01–P12`)

| 编号 | 所属阶段 | 原则标题 | 核心铁律 (`rule`) | 散户常见陷阱 (`trap`) |
| :--- | :--- | :--- | :--- | :--- |
| **`P01`** | `S1` 环境与时间门 | **专注日内单波段，拒绝高频刷单** | 只寻找高确定性的日内单边价格腿（Intraday Price Leg），用微型合约（MNQ/MES）或模拟盘练出肌肉记忆。 | 把导师演示的高频多空反手当作新手模仿目标，在噪音中频繁止损。 |
| **`P02`** | `S2` 流动性地图 | **价格的双重宿命：猎杀止损或回补失衡** | 价格运动只有两个底层驱动：① 去打掉旧高/旧低外侧的止损单（Liquidity）；② 去回补价格失衡区（Imbalance / FVG）。 | 用滞后均线或震荡指标猜顶摸底，看不懂大资金真正想去的价格磁铁（DOL）。 |
| **`P03`** | `S2` 流动性地图 | **散户的双顶/双底阻力支撑 = 算法的止损提款机** | 平滑的相对等高点（Equal Highs）上方聚集买方止损（BSL）；旧低点下方聚集卖方止损（SSL）。越干净的等高/等低点越必然被刺穿。 | 看到双顶就做空并把止损放在双顶正上方，沦为算法建仓的流动性燃料。 |
| **`P04`** | `S3` 猎杀与陷阱 | **开盘初段反向诱导（Sucker Play）识别** | 大周期看跌但上方 BSL 未扫前，早盘先往下跌破小低点往往是诱空陷阱；必须等掉头向上刺穿上方 BSL 后才是真做空窗口。 | 一开盘看到顺势小破位就急不可耐追单，被随后的反向拉升扫损爆仓。 |
| **`P05`** | `S4` 位移与扳机 | **高周期扫损 + 低周期结构破坏（BMS / MSS）** | 在 15m/1H 流动性池被刺穿后，切入 5m/2m/1m 等待价格以高能量位移（Displacement）干脆击穿最近的短期波段高/低点。 | 在高周期高点刚被触及、低周期尚未出现任何结构破坏时就左侧摸顶。 |
| **`P06`** | `S4` 位移与扳机 | **订单块开盘价吞没 = 交付状态转换（State of Delivery）** | 扫低点前最后一根/连串阴线为看涨 OB（扫高点前最后阳线为看跌 OB）；当位移 K 线突破该 OB 开盘价瞬间，交付状态正式翻转。 | 把任意一根普通阴线/阳线都当成订单块，忽略了“必须伴随流动性清扫与位移”的前提。 |
| **`P07`** | `S5` 均衡矩阵 | **50% 斐波那契均衡过滤（只买折价、只卖溢价）** | 从位移波段起点拉到终点取 `0.5` 中轴：做空只看 `>0.5` 溢价区看跌 FVG；做多只看 `<0.5` 折价区看涨 FVG。 | 在高于 50% 的溢价区追多，或在低于 50% 的折价区追空，盈亏比严重劣化。 |
| **`P08`** | `S5` 均衡矩阵 | **三 K 线公允价值缺口（FVG）挂单铁律** | 第 1 根影线与第 3 根影线不重叠留下的第 2 根实体缺口即为 FVG。做空在阳线回抽进看跌 FVG 时进，做多在阴线回抽进看涨 FVG 时进。 | 害怕踏空（FOMO）在位移大阴/大阳收盘瞬间市价追单，回抽时因浮亏过大被迫割肉在进场点。 |
| **`P09`** | `S5` 均衡矩阵 | **内部区间流动性（IRL）→ 外部区间流动性（ERL）止盈链** | 在外部流动性被扫后进场，第一止盈设在对侧 `<0.5`（或 `>0.5`）的内部反向 FVG，终极止盈设在对侧外部波段高低点（BSL/SSL）。 | 不分批止盈或把止盈设在还没跨过 50% 均衡线的半路位置。 |
| **`P10`** | `S1` 环境与时间门 | **纽约算法时钟：`08:30` 与 `13:30` 窗口 vs `12:00` 午休禁区** | 早盘看 `08:30` 数据脉冲与 `09:30` 现货开盘；`12:00–13:00` 纽约午休无条件空仓；下午盘看 `13:30` 二次扫损与 `15:00–16:00` MOC 尾盘加速。 | 在 `12:00–13:00` 纽约午休垃圾时间频繁开仓，把早盘利润全部回吐。 |
| **`P11`** | `S3` 猎杀与陷阱 | **三推衰竭模式（Three Drives Pattern）与无 FVG 过滤** | 冲击流动性池常走出三次推高/推低；若刺穿高低点后的第一波回落内部完全没有 FVG，必须按兵不动（Wait），防范再创新高/新低。 | 在第一波毫无失衡缺口的软弱回落中抢跑进场，被第三推直接打爆止损。 |
| **`P12`** | `S6` 手帐复盘 | **Ep.04 四维标准化复盘手帐** | 每天收盘在 `2m/5m` 图上固定标注 4 项数据：FVG 入场价、止损位、目标点差（Handles）与折算合约美元价值，用百张图谱消除犹豫。 | 复盘只看盈亏结果或幻想吃满最高到最低整段，不记录标准化的 FVG 进出场数据。 |

## 二、五周期剥洋葱标准矩阵 (`1W → 1D → 1H → 15m → 2m/1m`)

1. **`1W` 周线**：确认大资金刚拿掉了哪一侧历史高低点，当前周 K 线向哪一侧扩张。
2. **`1D` 日线**：锁定最近未清扫的摆动高点（BSL）、摆动低点（SSL）或日线失衡区（FVG），确立当日方向偏见（Daily Bias / Draw on Liquidity）。
3. **`1H` 小时线**：识别开盘前的诱多/诱空结构（如先跌破短期小低点诱导散户追空）。
4. **`15m` 猎杀窗口**：框出平头高点（Equal Highs）或时段高低点，等待 `08:30` / `09:30` / `13:30` 刺穿该流动性池（Stop Hunt）。
5. **`5m / 2m / 1m` 执行显微镜**：确认 BMS/MSS + Displacement → 拉 `0.5` 均衡线 → 在折价/溢价区 FVG（+ OB）挂限价单 → 对侧内部 FVG 与外部高低点止盈。
