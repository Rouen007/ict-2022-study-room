## 先选模型，再判断状态

1. 明确本次是在解释、对照、历史复盘还是合成练习；纯解释不用生成交易计划。
2. 一次执行判断先选择一个具名模型与版本，声明标的、合约、周期、时段、当时可见证据。其他体系只提供额外观察，不能临时替换入场、止损或退出规则。
3. 有冲突时写出各自规则和当前缺口；保持待定或放弃该模型，不用“多体系共振”掩盖矛盾。
4. 跨体系新组合属于待验证模型，必须先定义条件、失效、风险与对照样本；不归因给任何一位原作者，也不自动加入基础题库评分。

## 已发现冲突与正确处理

| 原稿问题 | 使用时的处理 |
| --- | --- |
| 决策树统一要求≥1.5R，而2C卡片目标为1R | 每个模型分别声明门槛与目标。若用户另定统一≥1.5R，则1R目标方案被过滤；不能悄悄改止盈或把新门槛归给作者。 |
| 做空仍套用多头的 `(T-E)/(E-S)` | 先检方向：多单S<E<T；空单T<E<S。风险有效后用 `abs(T-E)/abs(E-S)` 表达计划空间R；分别注明费用、滑点和成交假设。 |
| “走势不顺立即BE” | BE是意图或参考价，不是成交保证。分开提前退出、移动止损与实际成交；扣费后未必保本，也不能为等回本而拖延原失效退出。 |
| 所有模型都要求扫损、MSS或固定09:30静默 | 这类条件只约束明确采用它的模型或训练版本；不能自动施加到2C或Junkman。 |
| 固定15点、5点、1tick阈值 | 先核对品种、合约、周期、最小跳动、波动与原例前提；缺上下文时不移植到其他标的。 |
| 正Gamma、Midnight与London Low组合就定义“超级趋势日” | 作为待验证假设保留，不能单凭组合宣布趋势或方向已确认。缺来源／当前数据时不选该卡做执行依据。 |
| 三套信号重叠就称A+或胜率更高 | 只记为候选条件重叠，不能假设它们提供独立证据；统计优势需要定义样本、失败及成本后验证。 |
| “36笔82%胜率2.2均R”等数字 | 标为旧材料中的统计陈述；需逐笔记录、分母、R定义与费用口径，不能推广为策略长期胜率。 |
| “两周建立专业盘感”“30秒必须答对” | 计时只用于训练；先记录证据、动作与理由，揭晓后比较流程，不能按盈利结果倒推能力。 |

## 对照记录的最小信息

记录 `modelId/modelVersion`、作者或材料来源、原文起止时间／消息或页码、原图路径、证据状态、适用环境、触发、失效、目标与管理、限制／反例。已有JSON schema与App页面尚未统一支持这些字段时，可先写在笔记中，不虚构已接入功能。

同一英文术语在不同人物体系中不自动同义；2C的3根K总体50%、FVG的CE与所选区间均衡是三个坐标。B/T/E/S按所选模型的定义使用，不从本项目的重绘图倒推为作者通用定义。

## 增量学习与交付

已有本地转写先复用，缺口才定向补证据。用户只要求整理Skill时，不自动拉最新频道、读取整个社群、改写正式笔记或重新打包App。教学卡保持选学，基础训练继续沿用当前policyVersion。

交付说明本轮读了哪些原文／图、哪些仅定位、规则对照中发现的强化／限制／冲突、待核验项及下一步练习。新增内容不自动升级长期规则；归因与证据细节同 [evidence-and-extensions.md](evidence-and-extensions.md)。
